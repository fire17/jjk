core concepts

        
One vocabulary everywhere.

        

          

            
Safe Space

            
A repo that can remember meaningful states and let you get back to them.

          

          

            
State

            
A labeled snapshot with meaning: save, step, nice, star, or auto.

          

          

            
Lane

            
A named stream of work that can align with a Git branch or worktree.

          

          

            
Story

            
The memorable path through the work, not every move you made.

          

          

            
Freeze

            
A portable bundle and manifest for handoff, review, or backup.

          

          

            
Timeshift

            
An experimental path toward restoring more than files alone.

          

        

      


      

        
under the hood

        
Git-compatible. Jujutsu-aware. Human-first.

        

          

            
Git is still real

            
Snapshots live as real Git objects behind hidden refs. Push and pull still work.

          

          

            
Jujutsu improves recovery

            
When `jj` is available, `jjk` initializes colocated support and imports shared state.

          

          

            
The meaning layer is explicit

            
Labels, lanes, timeshifts, and freezes live in `.jjk`, where humans and agents can read them.

          

        

      


      

        
direction
